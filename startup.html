Company

Rent Hub by Arvion Technology

Sydney, Australia · Pre-seed · Built for AI startup programmes

Rent Hub is a direct rental marketplace for Sydney. It replaces the Facebook-group scramble with real listings, a swipe-based discovery flow for tenants, and a review queue that turns social posts into structured listings. Landlords and agents list directly; tenants message, inspect and move without an agency in the middle.

What is already built

  • Live website and demo: renthub.de5.net and /demo/ on a custom domain with HTTPS, 17 sample Sydney homes, browse, swipe, saved, messages and admin sync queue.
  • Android app: signed APK and Play-uploadable AAB built from a Flutter codebase; the APK runs on a Pixel emulator and is published on the release page.
  • Web app and API: Next.js marketplace with JWT auth, listings, messaging, inspections, saved searches, admin moderation and Facebook group sync queue; 73/73 API contract checks pass in the container image.
  • Engineering quality: 0 serious or critical accessibility violations across the public site and demo, Lighthouse 100 for accessibility, best practices and SEO (performance 79-96 depending on CDN latency), Docker image, backups and restore drill, CI for web, mobile, docker and accessibility.

Why this matters

Sydney renters still trawl Facebook groups and realestate.com, then deal with agency fees and slow application funnels. Rent Hub gives owners and agents a direct channel and gives tenants a fast, mobile-first way to find a home. The hard part is trust and moderation: synced posts need review, duplicate listings need detection, and support needs to answer quickly without a large team.

How AI credits would be used

We are applying to the Claude Startups programme for API credits and the Team plan. The first three Claude-powered features would be:

  1. Listing moderation: classify and normalise imported Facebook posts, detect duplicates and scam patterns, and draft an approve/reject reason for the admin queue.
  2. Support triage: read tenant and landlord messages, classify intent, draft replies with property context, and escalate inspection or safety issues.
  3. Listing assistant: turn a landlord's photos and notes into a structured listing draft (title, description, features, price guidance) with a human approval step.

Every AI output that reaches the marketplace stays behind human review in the admin console, and every generated listing keeps a moderation trail. The credits would cover the API usage needed to take these features from prototype to the first paying Sydney agents.
